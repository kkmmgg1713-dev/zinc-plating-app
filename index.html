자재를 선택하고 시료마다 20개의 도금 두께를 입력합니다.

1. 자재 관리

자재 추가 버튼으로 새 자재를 만들고, 연필 버튼으로 이름을 변경할 수 있습니다.

2. 키패드 입력

값을 입력하고 Enter를 누르면 다음 칸으로 이동합니다. 음수와 비정상 값은 저장되지 않습니다.

3. 음성 입력

“십이 점 오”처럼 말하세요. “다시”는 마지막 입력 취소, “다음”은 완료된 다음 시료로 이동합니다.

4. 저장과 복원

입력 즉시 자동 저장됩니다. CSV는 표 작업용, JSON은 전체 데이터 백업과 복원용입니다.

음성 인식은 HTTPS와 지원 브라우저가 필요하며 네트워크 상태에 영향을 받을 수 있습니다. Chrome 또는 Edge 사용을 권장합니다.
